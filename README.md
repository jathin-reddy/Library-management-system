# Library Management System

## Project Overview

The Library Management System is a database-driven project developed using MySQL. It is designed to manage library members, books, borrowing records, and current bookings using a relational database.

## Technologies Used

- MySQL
- MySQL Workbench
- SQL

## Database

**Database Name:** `librarydb`

### Tables

1. **members** – Stores information about library members.
2. **books** – Stores details of books available in the library.
3. **borrowing** – Maintains records of books borrowed by members.
4. **current_bookings** – Tracks current book bookings.

## Key Features

- Manage library member information
- Manage book records
- Maintain borrowing records
- Track current book bookings
- Store and retrieve data using SQL queries
- Relational database design using primary and foreign keys

## SQL Concepts Used

- Database and table creation
- Primary Keys
- Foreign Keys
- Constraints
- INSERT, UPDATE, DELETE operations
- SELECT queries
- Filtering and sorting
- Aggregate functions
- Joins
- Relational database concepts

## How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench and connect to your MySQL server.
3. Open the `library_management.sql` file.
4. Execute the SQL script.
5. The `librarydb` database and its tables will be created.
6. Run SQL queries to view and manage the library data.
